01

VIVA: Virtually Invincible Voice Assistant

An AI voice assistant that offers emotional support to people dealing with grief and bereavement.

  • RoleFront-end UI designer and builder
  • Team2 people, under faculty mentorship
  • WhenB.Tech final-year project, 2024
  • ToolsFigma, HTML, CSS, NLP, AI/ML

The problem

Grief is isolating, and a typical chatbot can feel cold at exactly the moment someone needs warmth. The interface had to feel safe, patient and human.

What I did

  • Designed the complete front-end UI for the voice assistant.
  • Created a calm, empathetic visual language: palette, typography, icons and interaction patterns.
  • Built the front end in HTML and CSS with a clean, responsive layout.
  • Designed the moments that matter most: asking for consent, the first greeting, and an honest “I don't know” reply.

Outcome

Presented the design rationale and UX decisions to faculty mentors. My teammate wrote the project documentation.

02

Yard Management System

User flows and operational dashboards for managing 500+ steel yards.

  • RoleUI/UX designer
  • ToolsFigma, Miro, Java, SQL

The problem

Hundreds of yards need one clear picture of what is where. Manual receipts and scattered information slow people down and hide problems.

What I did

  • Designed end-to-end user flows and operational dashboards.
  • Created wireframes, prototypes and interaction patterns.
  • Partnered with engineering to validate workflow logic and data presentation.

Outcome

Operational visibility up 25%. Automated receipt generation cut manual processing time by 40%.

03

Campus Placement Platform

A multi-role system connecting students, admins and recruiters.

  • RoleUI/UX designer
  • ToolsFigma, Miro, PHP, data visualization

The problem

Students, admins and recruiters each need something different from the same system. One confusing flow for all three slows everyone down.

What I did

  • Built a clear information architecture with workflows for each role.
  • Designed analytics dashboards for admins.
  • Ran usability tests and iterated, using research-driven interaction mapping.

Outcome

Admin review time down 30%. Student-employer connection rates up 35%.
